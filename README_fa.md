# WriteupRoulette

🌐 English: [README.md](README.md)

یک ابزار ساده ترمینالی برای هانترهای باگ‌بانتی که می‌خواهند به‌صورت مداوم و منظم ورایتاپ بخوانند.

به‌جای اینکه هر بار وقت خود را صرف انتخاب ورایتاپ بعدی کنید، WriteupRoulette به‌صورت تصادفی یک ورایتاپ انتخاب می‌کند و مواردی را که قبلاً خوانده‌اید دنبال می‌کند تا دوباره به شما نمایش داده نشوند.

## قابلیت‌ها

* انتخاب تصادفی ورایتاپ
* ثبت ورایتاپ‌های خوانده‌شده
* جلوگیری از انتخاب مجدد ورایتاپ‌های خوانده‌شده
* حذف ورایتاپ‌های نامناسب یا تکراری از لیست
* سبک و بدون وابستگی خارجی
* ذخیره‌سازی اطلاعات به‌صورت محلی

## منابع داده

لینک ورایتاپ‌ها از ریپازیتوری‌های زیر جمع‌آوری شده‌اند:

* https://github.com/devanshbatham/Awesome-Bugbounty-Writeups
* https://github.com/Voorivex/bb-resouces

تمام اعتبار این مجموعه‌ها متعلق به نگهدارندگان و مشارکت‌کنندگان آن‌ها است.

## نصب

ابتدا ریپو را دریافت کنید:

```bash
git clone https://github.com/NakuTenshi/WriteupRoulette.git
cd WriteupRoulette
```

سپس اسکریپت نصب را اجرا کنید:

```bash
chmod +x install.sh
./install.sh
```

و بعد با اجرا کنید:
```bash
writeuproulette
```


یا مستقیماً برنامه را بدون نیاز به نصب اجرا کنید:

```bash
python3 writeuproulette.py
```

## نحوه استفاده

پس از اجرا، برنامه یک ورایتاپ تصادفی انتخاب می‌کند و منوی زیر را نمایش می‌دهد:

```text
[1] Mark As Readed
[2] Choice Another One
[3] Remove It from List
```

### گزینه 1

ورایتاپ انتخاب‌شده را به لیست موارد خوانده‌شده منتقل می‌کند.

پس از این کار، آن ورایتاپ دیگر در انتخاب‌های تصادفی نمایش داده نخواهد شد.

### گزینه 2

یک ورایتاپ تصادفی دیگر انتخاب می‌کند.

### گزینه 3

ورایتاپ را بدون ثبت به‌عنوان خوانده‌شده از لیست حذف می‌کند.

مناسب برای:

* لینک‌های خراب
* موارد تکراری
* ورایتاپ‌هایی که علاقه‌ای به مطالعه آن‌ها ندارید

## محل ذخیره‌سازی

در صورت نصب:

```text
~/.local/share/writeups/
```

فایل‌های مورد استفاده:

```text
not_readed_writeups.txt
readed_writeups.txt
```
